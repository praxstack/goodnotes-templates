# Prax GoodNotes Journal v9

This pack is built as **A4 GoodNotes stationery**, not as a web app.

Flow: HTML page designs -> A4 printable layouts -> PDF export -> GoodNotes import.

## Main outputs

- `html/pages/` - individual A4 HTML page designs.
- `html/combined/` - combined printable HTML files for PDF export.
- `pdf/` - generated A4 PDFs.
- `stickers/svg/` - individual SVG stickers.
- `stickers/sheet/stickers-sheet-v9.svg` - all stickers on one sheet.
- `source-notes/decoded-brief.md` - what was carried forward from v5/v6/v7 and therapy bundles.

## Journal structure

1. Daily Survival Journal - tiny daily pages for check-in, brain dump, task start, reset, evening close.
2. Therapy Homework Journal - CBT, body tracking, shame mountain/jar, avoidance loop, identity/value, 30-min break experiment.
3. Shelf Inserts - stock-up, processing jars, gratitude, letters, scene capture, permission/quote, loose page.

## Print settings

Use A4, no margins, print background graphics. Import PDFs into GoodNotes.

## Safety

This is a personal reflection aid, not therapy, diagnosis, or medical advice. Use it alongside your therapist/doctor.
