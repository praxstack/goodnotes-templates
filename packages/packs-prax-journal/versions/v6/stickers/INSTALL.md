# v6 sticker library — Goodnotes import

Forty-one SVG stickers, one per file, sized 256×256 with transparent background and pack-coloured stroke. Drop them into Goodnotes once and reuse forever.

---

## 1. One-time setup — Goodnotes Elements panel

This is the recommended path. Stickers live as reusable Elements; you tap to drop, then resize on the page.

1. AirDrop / iCloud Drive / email the entire `stickers/` folder to your iPad.
2. In Goodnotes, open any notebook. Tap the **Elements** tool (the sticker-stack icon in the toolbar).
3. Tap **Edit** → **+ Collection** → name it *Prax Journal v6*.
4. Tap **+ Element** → **Import from Files** → select all 41 SVGs at once.
5. Goodnotes will ingest them as scalable vectors. Stroke and colour render exactly as designed.

You now have a permanent collection. From any v6 page (or any other notebook), tap Elements, tap *Prax Journal v6*, tap a sticker, drop it on the page. Resize with the corner handle — they stay crisp at any size because they're vector.

> **Tip.** Goodnotes lets you reorder Elements within a collection. Drag *01-restlessness-named* and *13-heavy-but-here* to the top of the panel — those are the most-stamped on heavy days, and shaving two taps off them matters at 9pm Tuesday.

---

## 2. Alternative — sticker library page in split-view

If the Elements panel feels like too much setup, there's a fallback: page 21 of the master PDF (`pages/21-sticker-library.html` rendered) is the full 41-card sticker reference.

1. Open `v6-prax-journal.pdf` in Goodnotes.
2. Open today's daily page in another notebook (or the same notebook).
3. Use **Split View** (iPadOS) to put the sticker library on one side, the daily page on the other.
4. On the sticker library, use the **lasso** tool to circle a sticker, tap **Copy**.
5. On the daily page, tap and **Paste**.

This is slower per-stamp but skips the Element-panel setup. Recommended only for the first week — switch to the Elements panel once you know which stickers you reach for most.

## 4. Name → emotional moment lookup

Sorted by the *felt sense* you'd reach for in the moment.

| When the moment is… | Reach for |
|---|---|
| restless and you put it into words | `01-restlessness-named` |
| restless and you walked it off | `30-if-restless-then-walked` |
| phone in your hand without choosing | `04-phone-reach-noticed` / `31-if-phone-then-one-word-why` |
| spiralling, then body-scanned | `32-if-spiraling-then-body-scan` |
| heavy and you still showed up | `13-heavy-but-here` + `24-permission-to-be-tired` |
| numb and you didn't pretend otherwise | `15-numb-acknowledged` + `37-if-numb-then-walked-to-window` |
| grief came up and you sat with it | `22-ria-thread-followed` / `34-if-ria-then-sat` |
| an identity question stayed open | `21-identity-question-held` + `27-permission-to-not-know` |
| you broke and came back clean | `06-break-taken` + `07-break-returned` |
| you were wrong and tried again | `28-permission-to-be-wrong` |
| crisis hour, you stayed | `40-stayed-through` (+ `38` if you called) |
| Q9 arrived | `39-phq9-q9-acknowledged` (then `38` within 24h if recurring) |
| the small dish-washed kind of win | `10-win-stamped` |
| you ate the frog | `11-frog-eaten` |

The kit's grammar is compound. A complete day might stamp three: a mood (Pack 4), a permission (Pack 8), and an if-then (Pack 9). One stamp is also a complete day. Zero stamps is also a complete day.

## PNG variants

Each SVG is also available as a 1024x1024 transparent PNG in `stickers/png/`.

Use SVGs when you have a tool that supports vector (Goodnotes 6 does — recommended for crispness).
Use PNGs when sharing with apps that only accept raster (most iPad note apps).
